ChimeraVPN v1.0.1

Secure WireGuard-based VPN client by ChimeraSec

Downloads

macOS

Universal binary — Intel & Apple Silicon, macOS 11+

Download .pkg installer

Or install via Homebrew:

brew install --cask chimera-sec/tap/chimeravpn

Windows

64-bit, Windows 10+

Download installer CLI only

Windows may show a SmartScreen warning — click "More info" then "Run anyway".

Debian / Ubuntu

amd64 & arm64

# Add repository (one-time)
echo "deb [trusted=yes] https://CHIMERA-SEC.github.io/downloads/apt stable main" \
  | sudo tee /etc/apt/sources.list.d/chimeravpn.list

# Install
sudo apt update && sudo apt install chimeravpn

# Update (future versions)
sudo apt update && sudo apt upgrade chimeravpn

Fedora / RHEL / CentOS

x86_64 & aarch64

# Add repository (one-time)
sudo tee /etc/yum.repos.d/chimeravpn.repo << 'EOF'
[chimeravpn]
name=ChimeraVPN
baseurl=https://CHIMERA-SEC.github.io/downloads/yum
enabled=1
gpgcheck=0
EOF

# Install
sudo dnf install chimeravpn

# Update (future versions)
sudo dnf upgrade chimeravpn

Quick Start

# Connect to your network
chimeravpn up

# Check status
chimeravpn status

# Disconnect
chimeravpn down
